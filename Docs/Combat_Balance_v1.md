# Aura 战斗数值基线：DemoBalanced_v1_4

> 2026-10-26 新技能数值与抗性以 [技能元素交互与三级进化实施方案](Skill_Elemental_Rework.md) 为准，本文件其余表格为历史基线。

> 历史版本说明：本文件保留 v1.4 的调参依据，不再代表当前资源循环。自 2026-10-13 起，人物按 XP 阈值自动升至最高 10 级，升级不消耗魂；大魔法师只处理技能、连携与洗点。战斗/脱战、击杀、Combo、装备与最大法力成长均不补当前法力；常规战斗与探索中通过蓝瓶回复，激活检查点时全队生命和法力回满。当前实现与验收规则以《Aura GAS RPG Demo 综合开发计划书》顶部的现行规则为准。

## 配置入口

运行时唯一配置资产：`/Game/Aura/Data/DA_CombatBalance`

它统一管理玩家属性、回蓝与升级曲线、局内三选一强化、三项玩家技能、Ghoul、精英萨满、Demon Boss、AI 感知距离、拾取/宝箱恢复量，以及三场强制遭遇的刷怪数量。C++ 中保留同结构的安全回退值；正常运行时必须加载上述资产。

技能消耗、冷却、眩晕、周期回蓝和拾取恢复均通过 GAS `SetByCaller` 使用资产中的实时值，不再由 GameplayEffect 类中的固定常量决定。

## 玩家与资源循环

| 项目 | 数值 |
|---|---:|
| 最大生命 | 100 |
| 最大法力 | 50 |
| 战斗中回蓝 | 1/秒 |
| 脱战回蓝 | 6/秒 |
| 脱战判定延迟 | 3 秒 |
| 回血拾取 | 35 |
| 回蓝拾取 | 20 |
| 教学地图拾取刷新 | 5 秒 |
| 宝箱恢复 | 35 生命 + 20 法力 |

50 点法力刚好支持一轮 `Q + E + Q`（18 + 14 + 18），技能冷却期间可用免费 FireBolt 持续战斗并等待回蓝。战斗回蓝只承担容错和长战续航，脱战回蓝负责恢复下一场战斗的基础资源，不鼓励在战斗中原地等待。

## 玩家成长

| 项目 | 数值 |
|---|---:|
| 等级上限 | 5 |
| 逐级升级需求 | 60 / 100 / 140 / 180 XP |
| 每级最大生命 | +15 |
| 每级最大法力 | +5 |
| 每级力量 / 智力 / 护甲 | +2 / +2 / +1 |
| 每级技能伤害 | +10%（加法累计） |

经验使用本轮累计值，达到阈值后立即升级；提升的生命与法力上限会同步补上新增容量。等级与累计经验在检查点保存，死亡重载后按等级重新构建 GAS 属性。满级技能伤害倍率为 `1.40`。

## 局内宝箱强化

两座支路宝箱初始处于封印状态：下层北支路进入后生成 2 只 Ghoul，二层南支路生成 1 只精英萨满；守卫全部击败后宝箱才会解锁。已清场未领取与已领取状态都会随本轮检查点保留。领取时先恢复 `35 生命 + 20 法力`，再随机展示三个不重复选项。玩家必须点击卡片或按 `1/2/3` 选择一个；选择期间移动、观察和施法输入锁定，玩家免疫伤害。每项最多 3 层，升级只在当前闯关生效。

| 强化 | 每层效果 |
|---|---:|
| Ember Core | FireBolt 伤害 +15% |
| Arcane Focus | Q 伤害 +20%，范围半径 +10% |
| Storm Sigil | E 伤害 +20%，眩晕 +0.25 秒 |
| Vitality | 最大生命 +20，并补充新增容量 |
| Mana Spring | 最大法力 +10，战斗/脱战回蓝 +0.4/秒 |
| Spellweaver | FireBolt、Q、E 伤害全部 +8% |

专属技能强化与等级/Spellweaver 倍率采用乘法组合。局内强化、已领取宝箱和等级/经验均随当前检查点保留；无检查点死亡则重置本轮构筑，避免重复领取支路宝箱。

## 玩家技能

| 技能 | 伤害 | 蓝耗 | 冷却 | 战术定位 |
|---|---:|---:|---:|---|
| 左键 FireBolt | 15 | 0 | 0.75 秒 | 免费填充攻击，保证零蓝时仍可战斗 |
| Q Arcane Shards | 50/目标 | 18 | 5 秒 | 300uu 高伤范围清群，900uu 选点 |
| E Shock | 40 | 14 | 6 秒 | 950uu 爆发控制，眩晕 1.75 秒 |

FireBolt 理论持续输出为 20 DPS，定位是稳定但较慢的免费填充。Q 对单体伤害约为 FireBolt 的 3.3 倍，命中三只敌人时造成 150 点总伤害；E 单次伤害约为 FireBolt 的 2.7 倍，并附带 1.75 秒控制。普通 Ghoul 可由 `Q + E + 一发 FireBolt` 击杀，玩家花费 32 蓝即可显著缩短战斗，因此技能在单体和群体场景下都有明确诱惑力。

## 敌人与 Boss

| 单位 | 生命 | 主要伤害 | 节奏/奖励 |
|---|---:|---:|---|
| Ghoul | 100 | 爪击 15 | 0.88 秒命中，1.35 秒攻击间隔；2 蓝 + 25 XP |
| Shaman Elite | 200 | 火球 20 | 0.8 秒预警，3 秒冷却；5 蓝 + 75 XP |
| Demon Lord | 450 | 一阶段爪 18；二阶段爪 22；甩尾 28；投掷 24 | 50% 血转阶段；5 蓝 + 250 XP |

普通 Ghoul 需要七发 FireBolt；萨满需要十四发。Boss 的裸 FireBolt 击杀需求为三十发，因此合理穿插 Q/E 会明显缩短战斗；转阶段、范围规避和技能窗口共同形成两段清晰节奏。

## 遭遇预算

| 内容 | 数量 |
|---|---:|
| 外层守卫 | 3 Ghoul |
| 精英房 | 1 Shaman Elite |
| Boss 房 | 1 Demon Lord |
| 奖励支路守卫 | 2 Ghoul + 1 Shaman Elite |
| 恢复支路游荡敌人 | 2 Ghoul |

强制路线固定为 3/1/1；关卡中的 Spawn Point 决定位置，Data Asset 决定每个遭遇实际采用多少个 Spawn Point。配置数量大于可用点位时会写入错误日志并只使用已有点位。

只走主路时，Boss 前累计 150 XP；清完四只可选 Ghoul 和一只可选精英萨满后为 325 XP，能以更高等级进入 Boss 房。全清并击败 Boss 共 575 XP，达到 5 级上限，因此支路战斗具备明确成长收益。

## 调参规则

1. 在内容浏览器打开 `Content/Aura/Data/DA_CombatBalance`。
2. 一次只调整一个系统，并同步修改 `Balance Version`。
3. 保持以下约束：感知半径 `<` 丢失目标半径 `<=` 脱战半径；萨满后撤距离 `<` 理想距离 `<=` 攻击距离；Boss 近战距离 `<=` 甩尾半径 `<=` 投掷距离。
4. 运行 `Scripts/validate_combat_balance_data.py` 做资产校验，再执行控制台命令 `AuraTestCombatBalance`、`AuraTestProgression`、`AuraTestRunUpgrades`、`AuraTestTreasureCaches`、Q/E、回蓝、萨满和 Boss 烟测。
