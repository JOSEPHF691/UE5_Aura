# 2026-10-26 技能元素交互与三级进化实施方案

本方案取代旧三条连携及连携点学习规则。保留当前地图、单人/双人流程、角色十级成长与每级技能点；本轮不修改场景资产。

## 已确认规则

- 删除火球→Q、Q→E、E→火球及过载增益，取消大魔法师连携页、连携点与 L3/6/9 连携点奖励。
- 火球有效命中必定附着余烬，雷电命中消费余烬并引爆，作为技能固有交互；低概率点燃为独立持续伤害。首版保留个人附着归属，不额外引入跨玩家标记争抢。
- 火球点燃概率按技能 Rank 1–4 为 8%/12%/16%/20%；同次施法对同一目标仅判定一次。点燃持续 3 秒，不无限叠层，后续有效施法可刷新。
- Q Rank 1 起造成范围伤害和减速。普通/精英/BOSS 减速初值 30%/15%/8%，持续 3 秒；控制强度按怪物类型和当前状态，而非单纯按等级。
- Q Rank 3 必须选择「水晶囚笼」或「晶簇回响」。水晶普通怪持续 3 秒、精英 1.5 秒；BOSS 常态不冻结，破韧窗口内只允许不超过窗口剩余时间的控制。水晶有独立耐久，怪物本体正常受伤，同时扣水晶耐久；耐久按约 2.5 次当前普通火球伤害计算。每颗三火球都独立扣耐久，同一水晶只爆炸一次；自然挣脱不爆炸。
- 晶簇回响为初始 Q 加三轮向外扩散的子晶簇，间隔 0.45 秒，伤害系数 45%/30%/20%。每轮四个子晶簇向四周逐步远离中心，子晶簇不递归生成；只对同一子晶簇重复命中去重，不设同轮全局限伤。生成点须贴地、限高并检查墙体，不能跨楼层结算。
- E 基础直线伤害附加约 4 秒麻痹，每 1.2 秒尝试一次短控制；替换原 1.75 秒直接长眩晕。普通/精英单次控制 0.2/0.1 秒，BOSS 通过韧性削减产生控制，阶段转换仍无敌。
- E Rank 3 必须选择「雷电领域」或「降下雷罚」。雷电领域保留方向选点，扇形初始命中后残留 3 秒，周期小额伤害并施加麻痹；降下雷罚改为地面区域选点，固定三道落雷、每道间隔 0.6 秒，区域内优先随机选择尚未被击中的有效敌人，各造成小范围伤害和麻痹。
- 各次 E 施法对同一目标最多引爆一次余烬；雷场/雷罚共享这次施法身份。衍生爆炸、点燃不再触发点燃、余烬或晶爆，避免递归。
- 短眩晕、破韧和结晶统一经过敌人的控制入口，使用怪物共享的控制保护窗口；双人不能各算一套免疫。减速取较强值，不累加；麻痹不因双人施加而翻倍触发。

## 成长与存档

技能等级仍为 0–4，角色等级仍为 1–10。火球原有互斥进化保留，Q/E 增加独立进化字段。每级技能点预算保持原样，不把废弃连携点换成技能点。

SaveGame 升至 v6：先按来源版本校验旧档，再迁移；清除旧连携投入及未用点，保留等级、XP、魂、背包装备及地图进度。旧档已有 Rank 3/4 的 Q/E 可暂存「待选进化」，在大魔法师处免费选择后启用，不强制替玩家选择。洗点支持三个技能的进化分支，仍遵循原有洗点资源与点数预算。未来或异常存档拒绝回写。

## 实施顺序与验收

1. 数据/成长迁移：v6、进化字段、取消连携点与旧学习请求；原 v1–v5 校验仍可用于迁移前验证。
2. 战斗状态组件：余烬、点燃、减速、麻痹、水晶及共享控制保护，服务器权威复制状态与生命周期。
3. Q/E 进化：水晶、外扩回响、扇形雷场、区域雷罚；统一施法身份、伤害来源和效果清理。
4. 界面：大魔法师仅技能/进化/洗点；技能树、HUD、物品词条与提示删除旧连携语义；E 雷罚使用地面预览与确认快照。
5. 自动回归与画面检查：基础元素交互、三火球分别破晶、一次晶爆、自然挣脱、精英/BOSS 抗性、麻痹免控窗口、扩散几何及重复结算、扇形/雷罚多段、客户端状态复制、v5 隔离档迁移后重复读取、NPC 鼠标选择及旧救援回归。验证不覆盖或改写真实玩家存档，不以旧连携测试通过冒充新版验收。

### 技术实现与兼容边界

- `UAuraElementalStatusComponent` 保存敌人共享的元素状态、晶壳和控制保护，服务器执行结算并复制结果；伤害、生命属性和短眩晕继续经过 GAS。余烬及施法去重按施法者隔离，麻痹计时与控制保护由同一敌人统一维护。
- `AAuraElementalSpell` 承载有次数/时长上限的回响、雷场与雷罚，使用定时器，不逐帧 Tick。闲置状态组件关闭 Tick，死亡时清除状态；团灭清除持续场；持续雷电及点燃特效有清理入口。
- Q/E 三级升级先选择进化后扣点，洗点支持三个技能的分支。大魔法师真实 UMG 按钮已接入进化确认；HUD 增加晶壳耐久、点燃、麻痹和减速提示。
- E 雷罚使用地面预览与确认快照，客户端和服务器分别验证距离、楼层高度、地面及墙体。基础 E 和雷场仍用方向确认。
- v1–v5 按原版本预算校验后迁移至 v6；原有高阶 Q/E 标记为待选进化，免费补选不扣技能点。废弃连携结构、标签名及部分旧接口保留用于反序列化和历史代码兼容，游戏中不再分配连携点或触发旧三条连携。
- 旧 `run_combo_ability_smoke.ps1`、旧 M17 连携菜单断言等不再作为当前规则的验收依据；新版验收使用下面的脚本。旧版本实施记录不改写为新版结果。
